## Findings

1. **[P2] Заполнять вычислимое поле пульса независимо от другого** — `src/intervals.rs:133–135`. Если первый HR-сэмпл приходит позднее 60 секунд от начала тренировки (например, на 120-й секунде), а сет записан на 130-й, `hr_at(0)` возвращает `None`, тогда как `hr_max(0,130)` уже даёт измеренный `pulse_after`. Условие `if let (Some(before), Some(after))` отбрасывает оба значения: `sync` оставляет пустым даже вычислимое поле, в том числе если `pulse_before` был введён вручную. Нужен независимый расчёт/запись доступных полей; правило заполнения пустых полей — [AGENTS.md:90–95](/home/ryazanov/Development/fitness/majowuji/AGENTS.md#L90-L95).

2. **[P2] Отличать содержащую сессию от grace-хвоста до округления дистанции** — `src/intervals.rs:103–108`. Для реальных меток логирования с долями секунды (`Utc::now()`), если сессия A ещё содержит сет, а более поздняя B закончилась, например, за 0,5 секунды до него, `(t.date - B.end()).num_seconds()` равна нулю. Тогда обе дистанции равны нулю и tie-break выбирает B по более позднему старту, хотя по заявленному правилу содержащая A должна победить grace-хвост. Результат — чужой пульс B может быть записан навсегда, потому что повторный `sync` заполненные поля не меняет.

3. **[P2] Сделать рекомендацию `migrate` выполнимой для отклонённой схемы** — `src/db/mod.rs:173–180`. Новая проверка полного набора столбцов классифицирует существующую БД без `trainings.notes` как устаревшую (именно такой случай задаёт `outdated_trainings_columns_require_migrate`) и `list`/`stats` предлагают `majowuji migrate`. Но `init_schema()` не добавляет `notes` (`CREATE TABLE IF NOT EXISTS` существующую таблицу не меняет, отдельные `ALTER` есть лишь для `duration_secs`, двух pulse-полей и `user_id`), поэтому `migrate` заканчивается ошибкой проверки и ни один CLI-путь больше не обслуживает эту БД. Либо миграция должна довести такую схему до текущей, либо диагностировать её как неремонтопригодную, а не обещать однократное восстановление; контракт — [AGENTS.md:27–31](/home/ryazanov/Development/fitness/majowuji/AGENTS.md#L27-L31).
